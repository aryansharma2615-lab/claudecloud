# FarmHand end effectors — one system for parts, plates, door, screen, spool (researched 2026-10-02)

**How to read this.** Grades: A = built + documented + video + measured; B = built + photos/video; C = vendor spec; D = render/hearsay.
`[f]` = I fetched the page; `[s]` = number comes from a web-search result summary of the linked page (the page itself was blocked by the sandbox proxy, so **verify before it enters a BOM**). Almost everything is `[s]`: only github.com pages were fetchable, and the session-wide web-search cap (200) was hit mid-research, so topic 8 and parts of 6/7 are thin.
Prices: original currency as listed on the search snapshot 2026-10-02 (listing dates not shown); `~CAD` uses an **assumed** 1 USD = 1.4 CAD (no FX source fetched). Acronyms: PEI = polyetherimide (the print-sheet coating); TPU = thermoplastic polyurethane (flexible filament); FEM = finite element method (simulation); FSR = force-sensing resistor; AMS = Bambu's Automatic Material System (spool unit); EOAT = end-of-arm tooling; ISO = International Organization for Standardization; SWS = Schunk's *Schnellwechselsystem* (quick-change system); QC = quick change; kPa = kilopascal; psi = pounds per square inch; COP = Colombian peso; INR = Indian rupee.

**Numbers that decide the architecture** (all from rows below): (1) R4 in `prompts/A_robot_redesign.md` = 1.5 kg incl. tool, a 1.2 kg spool leaves **0.3 kg for tool + any coupling**; a bought quick-changer is 0.2 kg (OnRobot) to 0.36 kg (ATI QC-5). (2) Accuracy need is ±1 mm (R5) but even the *worst* documented changer (Prusa XL, dusty) is 0.08 mm: accuracy is not what kills changers. (3) What kills them is electrical pass-through, dust, loosening mounts and crashes. (4) Print farms that work (DHR) swap the whole plate and wrap the spool in a robot-friendly container instead of gripping raw objects.

## 4. Capacitive stylus "robot finger"
**Plain English.** A phone screen is a grid of tiny capacitors (rows send a weak AC signal, columns listen: "mutual capacitance"). A real finger is a conductor tied to ground through your body, so it steals a little of that signal and the controller sees one grid node drop. Plastic is an insulator and ground-less, so nothing is stolen and nothing changes. A robot needs a **conductive tip with a path to ground** (a wire to the device/chassis ground, or a big conductive mass) and a contact patch about the size of a fingertip. [PMC review](https://pmc.ncbi.nlm.nih.gov/articles/PMC8309784/) `[s]`.

## 9. Tool changer vs multi-mode hand (decision table)
| Criterion | Tool changer (3–4 tools) | Multi-mode hand | Winner |
|---|---|---|---|
| Mass at spool pose (0.3 kg left) | +0.2 to +0.36 kg for bought changers; printed coupling mass not documented | no extra coupling | hand |
| Accuracy | 5–40 µm printed/machined; 0.08 mm worst case documented | compliant fingers + camera, ±1 mm need | tie (need is loose) |
| Electrical signals | pogo pins reported problematic; E3D wired instead | fixed wiring, one harness | hand |
| Failure points | dock bolts loosen, dust, crashes, wear | fewer interfaces; wear parts = TPU pads, stylus tip | hand |
| Spool (v2) | dedicated mandrel tool fits naturally | cannot grip raw spool | changer (later) |
| Cost / time to first demo | machined or purchased couplings; docks to build | one gripper + passive add-ons | hand |

## What to take
- **Decision: multi-mode hand for v1, "dock-ready" flange for v2.** Build one hand; mount it on a printed Jubilee-type flange (3 steel balls in 3 V-seats + cam/twist lock, 40 µm class, passive tools only) so a spool/vacuum tool can be added later without redesigning the arm. Do **not** build a multi-tool changer with signal pass-through now (pogo failures, dust, 0.3 kg budget).
- **The hand in words:** self-centring parallel gripper (symmetric rack or linkage, 85–100 mm stroke class like the 2F-85) with swappable TPU fin-ray pads on rigid cores and a **replaceable steel "nail" tip** at the finger edge (fin-ray tips lose force at tip contact); motor-current grip sensing + an FSR pad; a spring-loaded **conductive stylus** (8–9 mm replaceable foam/fabric tip, wired to ground, FSR or load cell behind it, preload >1 N so it also works on a resistive Ender) that is either flush-retractable on the palm axis or flipped out by one micro servo; a fixed **hook** on the back of the hand; wrist camera on the flange side.
- **Plates:** put a standard printed tab/"shoe" on every plate (precedent: A1-mini swapper uses a shoe; DHR swaps whole plates) and grip the tab with the nail fingers while the arm peels. Suction is plan B, smooth side only; never rely on it for textured PEI until a leak test is done.
- **Parts:** grip only parts within stroke; for big/stuck parts swap the plate or push-off at a bin, do not try to span 300 mm.
- **Door:** grasp-handle with current-limited compliance (DoorBot pattern) with the hook as fallback; close by pushing with the back of the hand; gate on the H2S door-sensor state; measure latch force first.
- **Spool (v2):** put a printed hub plug/handle ring or a cartridge on every spool so the robot always grips the same feature (DHR pattern), carried by a separate mandrel/fork tool on the flange; check the 0.3 kg budget against the chosen arm.
- **Sensing:** motor current (free) + FSR contact + load cell on the stylus + a magnetic breakaway on the flange with a microswitch (design idea, no source).
